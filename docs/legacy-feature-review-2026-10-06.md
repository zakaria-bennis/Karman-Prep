# Legacy feature review and first implementation

Reviewed against the combined local candidate `ea8c03f`, on 2026-10-06. This review identifies product intent, verifies it against current source and available tests, and implements a bounded unfinished feature. It does not authorize deployment, payment changes, security configuration changes or lesson/video launch decisions.

## Result

Students can now reopen completed practice quizzes from their dashboard and review saved answers alongside current published questions and explanations. Incomplete attempts return to practice without exposing keys. The read path verifies the attempt belongs to the student; unpublished, withdrawn or moved questions retain their saved outcome but hide their current content. The mobile dashboard menu now has an accessible name and a minimum 44px touch target.

Work is isolated in `karman-legacy-feature-review`, branch `zakaria/legacy-feature-review`, based on `ea8c03f`. The original checkout, combined candidate, question-agent outputs, Box files, integrations and credentials remain unchanged. No production records, external messages or paid APIs were used.

## What was implemented and how to use it

From the student dashboard, choose **Quiz history**. A completed attempt offers **Review answers**; an unfinished attempt offers **Continue in practice**. The learning-history page also links to quiz history. Review pages show saved correctness/answer separately from current answer content and explanations. They do not rescore historical attempts or promise immutable question snapshots.

The read service validates the UUID, requests the attempt with both attempt ID and student Clerk ID, checks completion before reading responses/questions, and uses the normal student publication selector. Only student display fields cross the client boundary; internal processing metadata is omitted. Parent/tutor route protection remains the existing student layout; admin preview uses the effective student identity without writes.

Question/choice tables stay native accessible tables; math remains KaTeX; geometry/chart/image fallback uses the existing verified renderers. No question, figure, category or answer key was changed.
