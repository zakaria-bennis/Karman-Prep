# 21st.dev components in the parent portal

Each one was fetched on the paid tier, ported into this folder, recoloured
with Karman's tokens, its Lucide or other stock icons swapped for the design
system's, and credited in a comment at the top of the file that holds it. The
design system's own ports (the glass button 12460, the segmented control
23552, the toggle 43112, the sheet 31360, the locked panel 18228, the row
list 25353, the heatmap 36571, the skeleton 35156 and 29863, the count-up
20068, the progress bar 23549, the empty state 19749) are used as they are.
