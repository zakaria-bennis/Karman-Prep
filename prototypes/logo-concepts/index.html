Nothing here is on the live site. The files sit on their own branch in a pull request, so you can merge, change or drop them.

Lettering. Ten of the wordmarks start from free script typefaces (Great Vibes, Pinyon Script, Parisienne, Allura, Sacramento, Alex Brush, Mrs Saint Delafield, Monsieur La Doulaise, Italianno, Meow Script), all under the Open Font Licence, which allows use in a logo. Once you pick a direction, the letters should be redrawn by hand so the mark is yours alone, the way 11 already is.

Motion. Every mark and intro respects the device's reduced-motion setting: the logo simply appears, and the intro is skipped.
