# Logo concepts, round two (13 Nov 2026)

Zakaria passed on the script logos in round one and asked for something simpler that brings the brand to life: 12 ideas, 4 versions each.

Open `index.html`. Each version is shown large, next to the name as it would sit in the header, and at favicon size. Refer to them by number and letter (8B). `all-light.png` and `all-dark.png` show every version at rest.

- `svg/`: each version as a standalone SVG that follows light and dark mode.
- `tools/marks.py`: the shapes, drawn in code on a 100 by 100 grid. `msheet.py` renders the preview sheets and `mpage.py` builds the page. Version 8D uses the Young Serif K, through `../tools/lib.py`.

Nothing here is used by the site.
