# 21st.dev components used in the editorial direction

Searched 21st.dev first (2026-11-01) for the header, hero, theme switch, text reveal and pricing.
Each port is plain HTML, CSS and JS, recoloured with this page's tokens (paper, ink, marigold).
No Lucide icon survives: the two theme glyphs are drawn for Karman (an open circle, a half-filled circle).
