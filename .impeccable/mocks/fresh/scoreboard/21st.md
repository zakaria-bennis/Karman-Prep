# 21st.dev components used in "Scoreboard"

Searched 21st.dev first (number tickers, plan comparison tables, theme toggles). Three were
retrieved and ported to plain HTML, CSS and JS, recoloured with the page's tokens. No Lucide or
Remix icons survive: every icon on the page is drawn for Karman.

| 21st.dev id | Component | Author | Where it lives here | What changed in the port |
| --- | --- | --- | --- | --- |
| 20071 | Animate Digits | unlumen | `digits()` in `scoreboard.js`: the three official scores and the "days to go" count | React and motion/react springs replaced by the Web Animations API. Each digit sits in its own cell and blur-slides in, one after another, 80 ms apart. Critically damped (no bounce), skipped under reduced motion. |
| 21218 | Feature Comparison Table | olewandowski1 | The plans table (`#ladder`, built in `scoreboard.js`, styled in `scoreboard.css`) | A real `<table>` with a header row and tone-stepped rows kept, three columns (plan, price, what it includes). Removed: check and cross icons (rule 16), the "Most popular" badge and sparkle icon, the buttons in cells (rule 35), the 1px borders, the yes/no column. Stacks into one block per plan on a phone. |
| 37721 | Theme Switch | zweiundeins (MIT, ported from Starbase) | The Auto / Light / Dark switch in the footer (`#themeSwitch`) | Segmented radios kept, with the same sync idea (one choice, every control follows). Cookie replaced by `localStorage` key `karman-theme`. Icons redrawn (empty disc, full disc, half disc). Purple brand tokens replaced by the page's ground and ink. The header's single mode button uses the same state. |
