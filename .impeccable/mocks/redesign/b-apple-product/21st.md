# 21st.dev components in "b-apple-product"

Every component below was found with the 21st.dev search on 2026-11-01 (paid tier), read in full,
and ported to plain HTML, CSS and JS in this folder: no React, no Tailwind, no Lucide. Each one is
recoloured with Karman's tokens (off-white, night, black, marigold) and credited by id in a comment
at the place it lives. Icons inside them are drawn for Karman in `site.js` (`ICON`), one stroke,
one weight. The fix round of 2026-11-01 removed two (listed at the end) and changed four.

Removed in the fix round (replace, don't accumulate):

- 24622 Scroll Direction: Hide Header (motion.dev): a fixed header that returns on the way up sits over the text being read (rule 34; the judges counted 74 to 77 covered text boxes a page). The header now scrolls with the page.
- 20068 Count Up (unlumen): the 1235 and 1520 figures counted up as the reader arrived, a number that moves on scroll (rule 37). The figures are static.
